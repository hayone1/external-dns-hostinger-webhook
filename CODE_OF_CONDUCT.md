# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be kind and patient. Everyone was new once.
- Talk about the code, not the person.
- No harassment, insults or personal attacks, in any form.
- Help keep this a place where anyone can ask a question without feeling silly.

## Reporting

If someone breaks these rules, tell the maintainer privately through
[GitHub's private reporting](https://github.com/hayone1/external-dns-hostinger-webhook/security)
or by email to the address on the maintainer's GitHub profile. Reports are
kept private.

Maintainers may remove comments, code or issues that break these rules, and
may block people who keep breaking them.
